# mazu-learn-jp

Aplikasi web interaktif untuk belajar bahasa Jepang dari tingkat dasar (Hiragana/Katakana) hingga JLPT N5 dan N4. Dilengkapi dengan materi tata bahasa, kosakata, kanji, latihan membaca, dan latihan mendengar dengan fitur text-to-speech.

## Fitur

- **Huruf Dasar**: Hiragana dan Katakana lengkap dengan dakuten, handakuten, dan youon
- **JLPT N5**: 8 pola tata bahasa, 20+ kosakata, 80 kanji, dan percakapan dasar
- **JLPT N4**: 10 pola tata bahasa, 20+ kosakata, 160 kanji, dan percakapan menengah
- **Latihan Membaca (Dokkai)**: 15 teks (8 N5 + 7 N4) dengan furigana dan pertanyaan pemahaman
- **Latihan Mendengar (Choukai)**: 10 percakapan (5 N5 + 5 N4) dengan fitur text-to-speech
- **Flashcard Kanji Interaktif**: 240 kanji (80 N5 + 160 N4) dengan arti, onyomi, kunyomi, dan contoh
- **Toggle Section**: Setiap bagian dapat dibuka/tutup untuk pengalaman belajar yang lebih fokus
- **Responsive Design**: Tampilan optimal di desktop, tablet, dan mobile

## Teknologi

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- JavaScript (ES6+)
- Font Awesome 6.5.0
- Web Speech API (Text-to-Speech)
- JSON (Data storage)
